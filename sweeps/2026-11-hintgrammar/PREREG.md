## Hypothesis and scope

Every solved key in this puzzle family was announced in the puzzle's own
vocabulary or is a derivable math rule (PRIORS §1 [OURS+H]: DIVINITY,
FIRFUMFERENFE, φ(prime) for p56). #28 closed the RANDOM-seed generators.
#29 enumerates the structured, FLAT, APERIODIC generators built from
book-internal hints × operations. Periodic Vigenère L1–40 is already
excluded (MAP §eliminated: IoC·N=1.000 + doublet deficit jointly
unmatchable) — this campaign covers only the aperiodic remainder:

- **autokey** (key = seed then plaintext/ciphertext — Wulfic's queued claim
  "autokey to 12,863", MAP F18(ii));
- **running keys** from book-internal texts (dukotah's own armada18 key
  directory already treats LP1 texts as running keys);
- **derivable math streams** (primes, Fibonacci, φ, digit expansions).

External literary corpus (Emerson/Homer/Genesis/… in armada18) is EXCLUDED
from the hint list per PRIORS §1 [H]: the literary canon lives in CHAIN
stages, never as LP keytexts. Disclosed deviation risk: if the group broke
their own habit for LP2, this campaign cannot see it (L4).

## Emission model (all cells, as in #28)

`c_t = (p_t + σ·k_t) mod 29`, σ = ±1 both signs, anti-doublet rejection
loop with keyskip1 (reject consumes 1 key value); scoring is skip-tolerant
(≤12 extra consumptions per 120-rune window, 3.0 nats/each — the #28
registered DP relaxation, reused) OR direct (autokey/running decodes are
deterministic given the generator; tolerance applies only to the F-skip
variant below). F-skip variants: {off, on} — on = ᚠ in KEY positions is
null (does not advance key), the LP1 rule.

Letter→rune-value map for text hints (canonical gematria, 29 letters):
A=0…J=9, no K (K→C), L…N, no O? — pinned explicitly in `grammar.py` from
`core.validate.GEMATRIA`; conflations V→U, K→C, Z→S (PRIORS §2 [H]).
Digits→value: digit mod 29 (identity for 0..9).

## Cells (the finite grammar)

**K1 — plaintext-autokey.** k_t = p_{t−w} for t ≥ w; lag w ∈ [2..64], both
signs, F-skip {off,on}. Decode is direct recursion; statistic on body
[w, 12956). First w runes untested (seed word unknown) — L1.
**K2 — ciphertext-autokey.** k_t = c_{t−w}: p_t = c_t − σ·c_{t−w}; same
w-range, signs, F-skip. (Includes Wulfic's claim class.)
**K3 — running keys from pinned hints.** Hint list (each sha256-pinned in
metadata.json): `lp1_english_forward.txt`, `lp1_english_reversed.txt`
(armada18), scream314 LP1 rune index stream (2,798), solved LP1 plaintexts
+ p56 + p57 (regenerated by `core.validate`, content-pinned). Key stream =
hint values from offset t0, no cycling; t0 ∈ [0, |H|−200] (prefix ≥200
runes decodable); both signs; A=0 and A=1 spellings; forward/reverse.
**K4 — derivable math streams.** prime(n) mod 29 (n = 1..), fib(n) mod 29,
φ(n) mod 29, digits of 1033/3301 concatenation, π/e/√2 first 2,000 digits,
p56 hex digits; index offset 0..999; both signs. (φ(prime) is the p56
rule — included so the grammar provably contains a known solution.)

Total ≈ 2.6e5 deterministic decodes (K3 dominates). No seed search; this
is a grammar scan, not a keyspace sweep.

## Statistic, nulls, verdicts

Statistic = skeleton-pruned legal-crib count (core.skeleton, #21 skeleton;
36-word house list) at full length (K3: over the decodable prefix),
flag-for-oracle at ≥2 legal cribs on a page — NEVER auto-certified.
Quadgram LL reported descriptively.

Family-matched MC nulls (D=200, seed 20261229): K1/K2/K4 = corpus
page-permutation surrogates (destroys key-plaintext structure, preserves
length/marginals); K3 = hint-text permutation surrogates (preserves letter
structure, destroys word alignment). Verdict per cell, verbatim:

- **FLAGGED** — any page with ≥2 legal cribs above the cell's null max for
  that statistic: report to owner BEFORE any public statement.
- **CLOSED-NO-GRAMMAR** — no flag AND 20/20 plants ≥ null_max + 2.0.
- **UNPOWERED-NULL** — no flag but power gate fails: space stays OPEN.

## Disclosed limitations

- **L1** K1 first-w-runes untested (unknown seed); body statistic only.
- **L2** K3 prefix-limited by hint length (max 2,798 runes; tail 10,158
  runes unkeyed by these hints).
- **L3** lags/offsets bounded as registered (w ≤ 64, t0 full, idx ≤ 999).
- **L4** external literary hints excluded (PRIORS §1); other hint sources
  (printed digits as key DIRECTLY was #7; segments v2 groups) not here.
- **L5** keyskip2 autokey variants not included (keyskip2 excluded at power
  1.00 for random seeds by dukotah; for structured generators we keep
  keyskip1 + tolerant screen; disclosed asymmetry).
- **L6** transposition-of-key or key-feeding-back-through-atbash chains
  beyond F-skip are outside the registered grammar.
